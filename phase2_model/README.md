# Narrative check (stage 2)

Reviews a time entry's narrative the way a fee examiner would, and suggests a fix.

1. **Split** a block-billed entry into task lines whose times add up to the total.
2. **Expand** shorthand. Unambiguous shorthand is expanded; ambiguous shorthand ("rev") is left and flagged.
3. **Classify** each line. The entry gets the worst line's flag.
4. **Rewrite** with placeholders where information is missing. The model never guesses a name.
5. **Assemble** one block entry with per-task times, or separate entries if "no block billing" is selected.
6. **Re-check**: list the open placeholders, with candidates from the entry's other tasks and the matter's history.

## Folders

| Folder | What it is |
|---|---|
| `pipeline/` | The code the app runs (steps 1 to 6). The Docker image copies this folder. |
| `training/` | Scripts that build the training data, train the models, and evaluate them. |
| `models/` | Trained models. The classifier is in git; the rewriter (about 300 MB) is not. |
| `data/raw/` | Inputs, not in git: the balanced time entries, the gold labels, the shorthand banks. |
| `data/outputs/` | Generated by `training/`, not in git, except the hand audit `pairs_audit.csv`. |

`pipeline/`

| File | Step |
|---|---|
| `split_block.py` | 1. Split a block entry into task lines with hours |
| `expand_shorthand.py` | 2. Expand shorthand with `data/raw/shorthand_bank_v2.csv` |
| `review.py` | 3, 4 and 6. Runs the whole check: `Reviewer(models_dir).review(narrative, hours)` |
| `assemble.py` | 5. Put the task lines back into one entry, or separate entries |

`training/`

| File | What it does |
|---|---|
| `decontaminate.py` | Removes gold-set entries from the training data |
| `make_pairs.py` | Builds training pairs by damaging good lines on purpose |
| `eval_splitter.py` | Scores the splitter on synthetic blocks and the gold set |
| `train_classifier.py` | Trains the line classifier and reports on dev and gold |
| `train_rewriter.py` | Fine-tunes the rewriter (flan-t5-small) |

## Rebuilding the data and models

Run from this folder, in order:

```
python training/decontaminate.py
python training/make_pairs.py data/outputs/time_entries_decontaminated.csv data/raw/shorthand_bank_v2.csv data/outputs/pairs
python training/eval_splitter.py
python training/train_classifier.py
python training/train_rewriter.py --epochs 1
```

The classifier trains in seconds. The rewriter takes about 45 minutes per epoch on CPU and is optional; without it, the app rewrites with rules. `make_pairs.py` also needs `../shorthand_bank/rule_baseline.py`.

Then rebuild the app image (see `../docker/README.md`).

## Status

The models are trained on synthetic pairs: good lines with information removed on purpose. They show the infrastructure working, not final quality. On the gold set the classifier flags problems with about 0.5 precision and 0.5 recall, and it never predicts VAGUE, because the synthetic vague lines don't look like real vague entries (`models/classifier_report.json`). On ALL CAPS lines the rewriter sometimes changes words, so the app rejects any rewrite that adds a word not in the input and falls back to rules. The label set, the severity order and the pair audit are still open.
